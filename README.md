## 常见问题

**Q. 矩阵里那么多客户端，最少下几个？**  
A. 通常 **1 个维护中客户端** 即可。先定系统，再按「场景选型」挑一条线，避免同时装多个抢代理的工具。

**Q. 教程域名为什么是 clashclient.com？**  
A. 本仓定位是客户端资源分享，图文步骤集中在 clashclient.com 对应页面；安装包仍以各项目 **GitHub Releases**（或本页标明的备份仓）为准。

**Q. 标题写着 2026年11月更新，是不是软件也是这个月发的？**  
A. 不是。那是本 README 的整理月份；客户端版本以各自 Releases 的 Tag / 发布说明为准。

**Q. OpenWRT / 软路由？**  
A. 通常不与桌面 GUI 共用 Assets；查固件插件源或 mihomo 文档，配置与手机、电脑分开备份。

**Q. 还能用 Clash for Windows 吗？**  
A. 仅历史对照，不建议日常主用。请按「从旧版迁出」换到维护中客户端。

**Q. 订阅导入失败？**  
A. 核对订阅能否直连拉取、配置类型是否匹配，并查该客户端 Issues；本仓不代生成订阅。
